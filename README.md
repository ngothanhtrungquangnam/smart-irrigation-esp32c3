# ESP32-C3 Smart Irrigation System

## Overview

An automatic and manual plant irrigation system based on ESP32-C3.

## Hardware

- ESP32-C3
- Soil moisture sensor
- Water level sensor
- Relay module
- Water pump
- 16x2 I2C LCD
- Buzzer
- Push button

## Features

- Automatic irrigation based on soil moisture
- Manual watering mode
- Water level monitoring
- Low-water warning
- Blynk IoT monitoring
- LCD status display
- Hardware timer interrupt
- Button interrupt
- ADC sensor reading
- Hysteresis control

## Technologies

- ESP32-C3
- Arduino
- C++
- Blynk IoT
- I2C
- ADC
- Hardware Timer
- GPIO Interrupt
